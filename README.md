# 🤖 Multimodal Voice Assistant

An AI-powered multimodal voice assistant capable of understanding voice commands, generating intelligent responses, maintaining conversational memory, and interacting through speech. The assistant combines speech recognition, natural language processing, and vector database memory to provide an interactive AI experience.

## ✨ Features

- 🎤 Speech-to-Text using Whisper
- 🧠 Conversational AI using Large Language Models
- 🔊 Text-to-Speech responses
- 💬 Context-aware conversation memory with ChromaDB
- 🖼️ Image understanding support
- 🌐 Web-based interface
- ⚡ Fast API integration
- 🧹 Memory management utilities

## 🚀 Installation

```bash
git clone https://github.com/yourusername/multimodal-voice-assistant.git
cd multimodal-voice-assistant
pip install -r requirements.txt
```

Create a `.env` file and add your API keys.

Run the project:

```bash
python manage.py runserver
```
